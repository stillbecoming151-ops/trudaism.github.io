# Trudaism GitHub Pages Site

Minimal, beautiful website for Trudaism - truth as sacred framework.

## To Deploy
1. Create GitHub repo: `trudaism.github.io`
2. Push all files:
   ```bash
   git init
   git add .
   git commit -m "Initial Trudaism site"
   git branch -M main
   git remote add origin https://github.com/trudaism/trudaism.github.io.git
   git push -u origin main
   ```
3. Enable Pages in repo settings → Pages → Deploy from branch: main

## Files
- `index.html` - Landing page
- `foundations.html` - Full foundations document
- `practice.html` - Daily practice guide
- `community.html` - Links and connections
- `style.css` - Dark theme styling

## Style

- Georgia serif fonts
