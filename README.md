# Trudaism
Official repository for the Trudaism project - truth as sacred framework

## What is Trudaism?
A framework where:
- **God = Truth** - one reality, forever beyond full grasp but worth seeking
- **Honesty is sacred** - lies are blasphemy against truth itself  
- **We choose, not are chosen** - anyone joins by valuing truth over comfort
- **Faith as action paradox** - act boldly while knowing you're incomplete
- **Eternal seeking** - the asymptote is the practice itself
